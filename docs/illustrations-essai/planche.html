    Le parti pris

  • Le dessin dit la phrase.Chaque image reprend les mots du texte qu’elle accompagne, dans le même ordre.
  • Des objets, jamais de personnage.Les personnes sont des points ; le point jaune du logo, c’est vous.
  • Une seule main.Aplats, coins ronds, une épaisseur de trait, pas d’ombre floue ni de dégradé.
  • Peu de couleurs.Papier, menthe, sable et mandarine sur le vert ; le jaune une seule fois, là où l’œil doit se poser.
